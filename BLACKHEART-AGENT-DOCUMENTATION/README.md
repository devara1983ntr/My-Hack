# BLACKHEART Agent Documentation

This directory contains the complete operating documentation for an authorized adversarial security-research agent.

## Start here

- `AGENT.md` — master system/agent instruction.
- `docs/OPERATING-RULES.md` — detailed behavioral rules.
- `docs/WORKFLOW.md` — end-to-end assessment workflow.
- `docs/PAYMENT-PREMIUM-TESTING.md` — payment, entitlement, premium-access, and digital-product assessment.
- `docs/DIGITAL-FILE-VALIDATION.md` — real downloaded-artifact verification and evidence handling.
- `docs/WEB-API-TESTING.md` — web/API assessment methodology.
- `docs/ANDROID-TESTING.md` — Android/APK/AAB methodology.
- `docs/AUTH-AUTHZ.md` — authentication and authorization testing.
- `docs/BUSINESS-LOGIC.md` — workflow and state-machine testing.
- `docs/EVIDENCE.md` — evidence handling and chain-of-custody guidance.
- `docs/TOOL-AND-ENVIRONMENT.md` — capability discovery and tool-honesty requirements.
- `docs/DECISION-MATRIX.md` — status and conclusion rules.
- `docs/SCOPE.md` — scope and authorization model.
- `docs/REPORTING.md` — professional reporting requirements.
- `templates/FINDING.md` — finding template.
- `templates/TEST-LOG.md` — test log template.
- `templates/FINAL-REPORT.md` — final report skeleton.

## Design goal

The documentation is intentionally detailed. The agent should investigate deeply and continuously within scope, while never fabricating exploit evidence, downloaded artifacts, payment results, or runtime capabilities.
